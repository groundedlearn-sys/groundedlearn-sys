# 🌱 Grounded Learning  
**Learn Deeply. Build Wisely.**

Welcome to **Grounded Learning** — a calm, structured space for learning **Python**, **Data Structures & Algorithms**, **Data Science**, and **Machine Learning** through a first‑principles approach.  

I create educational content that blends:  
- Clear **PowerPoint / Google Slides**  
- Intuitive **Excalidraw whiteboard explanations**  
- Hands‑on **Jupyter Notebook walkthroughs**  
- Practical **VS Code examples**  

My goal is simple:  
Help learners understand concepts deeply, build confidently, and grow into thoughtful engineers.

---

## 📚 What You’ll Find Here
This GitHub profile is the **public teaching portfolio** for the Grounded Learning ecosystem.

Each repository is structured like a mini‑course:

- **python-foundations** — Core Python concepts explained from first principles  
- **dsa-grounded** — Intuitive DSA explanations with diagrams and code  
- **data-science-grounded** — Foundations of DS with notebooks and visual intuition  
- **machine-learning-grounded** — ML concepts, math intuition, and hands-on models  
- **ml-projects** — Real-world ML projects with clean structure  
- **whiteboard-explanations** — Excalidraw diagrams used in lessons  
- **slides-and-assets** — Teaching slides and visual assets  

Each repo includes:  
- Notebooks  
- Code examples  
- Slides  
- Whiteboard diagrams  
- Assignments  
- Solutions  
- Resources  
- Video links (as published)
